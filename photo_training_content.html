Interactive training · a real convolutional neural network

Train the filters. Follow the error. See the network change.

This lesson trains a compact image classifier from scratch in your browser. Two convolutional layers learn visual filters, and two dense layers combine their responses into deer, raccoon, or coyote predictions. Its 5,083 adjustable parameters really change when you train. It classifies a whole prepared image; it does not draw animal boxes. MegaDetector and SpeciesNet keep their existing pretrained weights.

Unpack the math, one operation at a time
1. Convolution shares a filter across positions

For output filter f at row r, column s, multiply each nearby input value by its matching kernel weight and add them:

a[f,r,s] = b[f] + Σc Σu Σv K[f,c,u,v] × x[c,r+u−1,s+v−1]

Here u,v run over the 3 × 3 window and c runs over input channels. The same weights are reused at every position. The first layer has 4 × (3 × 3 × 3 + 1) = 112 parameters; the second has 8 × (3 × 3 × 4 + 1) = 296.

2. ReLU, pooling, and dense layers transform the responses

ReLU computes h = max(0, a). Mean pooling averages each 2 × 2 group, reducing width and height by half. Flattening rearranges the 6 × 6 × 8 responses into 288 numbers; it does not learn weights.

The hidden dense layer computes h = ReLU(Wx + b) with 16 outputs and 288 × 16 + 16 = 4,624 parameters. The final layer makes three logits with 16 × 3 + 3 = 51 parameters. Total: 5,083.

3. Softmax and cross-entropy define the learning signal

For class scores z, softmax is p[k] = exp(z[k]) / Σj exp(z[j]). The implementation subtracts the largest score before exponentiating for numerical stability.

For one checked label t, the loss is L = −log(p[t]). Average this over the training batch. Its derivative with respect to each score is ∂L/∂z[k] = p[k] − y[k] for a single photo, where y is the one-hot checked target.

4. The chain rule reaches every trainable layer

Backpropagation combines local derivatives. Through a dense product, a weight's gradient is its input times the upstream gradient. Through a convolution, sum those products over all the positions sharing that weight. Mean pooling passes one quarter of the upstream gradient to each of its four inputs. ReLU passes a gradient only where its input was positive.

After averaging the batch gradients, stochastic gradient descent applies θnew = θold − learning_rate × ∂L/∂θ. This lesson uses a full batch. Training repeats this calculation; inference stops after the forward pass and makes no optimizer update.

Why random initialization? Identical zero filters can learn identical responses or leave ReLU paths inactive. Small seeded random weights let different filters start differently; Reset reproduces the same starting network for a fair comparison. Labels are supplied by people, not invented by the model.
