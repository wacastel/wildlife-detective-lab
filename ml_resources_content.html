Find data · know what you downloaded

Public camera-trap photos and published AI results

Photos, checked annotations, and model predictions are different things. Photos contain the evidence. Human annotations supply checked labels or boxes. MegaDetector results are machine-generated boxes, categories, and scores; they still need review and do not supply species identities.

Start with LILA's wildlife-data catalog, then open its separate published MegaDetector results index. “Already processed” usually means the original photographs plus a separate JSON file of predictions, rather than pictures with boxes permanently painted on them. These are public download sources; this app does not download a collection when you open this page.

Read the prediction file before trusting its boxes

Model versions differ. The downloads above use MDv5a or MDv1000-redwood; this lab uses its pinned compact V6 model. Their boxes and scores need not match. The maintained index also links other versions and raw alternatives.

RDE means repeat detection elimination. It helps suppress recurring false alarms, but can also suppress genuine detections. Some exports already omit low-scoring predictions. Keep that processing history instead of treating a filtered file as untouched output.

Public does not mean an independent test. Many LILA collections were used in MegaDetector training. Use these outputs for learning or carefully checked training workflows; they do not provide an unbiased MegaDetector accuracy benchmark.

A manageable first download: a few ENA24 photographs
  1. Open the ENA24 dataset page, read its license, and get its human metadata. Separately download the small MDv5a JSON ZIP above.
  2. Choose a few image records from the JSON. Use their full relative paths with the image base URL listed in LILA's image-access guide or dataset catalog CSV. Keep directory names; filenames alone can repeat.
  3. For example, this is an actual ENA24 camera-trap photograph. Download a small permitted selection rather than the entire image archive, and keep its source information.
  4. Follow the MegaDetector output specification: inspect model metadata, the category mapping, per-image failures, scores, and normalized [x, y, width, height] boxes. A failure is not the same as an empty detection list, and neither proves no animal was present.
  5. Match human annotations to the selected files for checking. To try the photos in this app, upload a few permitted files in Tab 2. The public JSON download is a separate reference; this app does not automatically import outside prediction files or pass them off as its own saved results.
Before downloading a collection
  1. Check permission. Read the image and annotation licenses, attribution requirements, and access rules. Public access does not mean unrestricted reuse.
  2. Start small. Inspect a sample or download selected files first. Some collections are enormous; storage, downloads, and cloud processing can cost money.
  3. Keep the recipe. Preserve image paths, dataset release, model version, score settings, and file hashes. Confirm whether a JSON file contains human annotations or AI predictions.
  4. Keep the test honest. Split encounters and sites before training. Do not turn unchecked MegaDetector predictions into claimed ground truth, or assume a public dataset was absent from a pretrained model's training data.

External links need an internet connection. Downloading a dataset does not automatically add it to this lab's chooser; start by selecting a few permitted JPEG, PNG, or WebP files for the existing lab.
